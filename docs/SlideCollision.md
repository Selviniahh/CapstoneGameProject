Dikdörtgende:

left
top
width
height

değerlerinden kenarlar şöyle hesaplanır:

Sol kenar  = left
Sağ kenar = left + width
Üst kenar = top
Alt kenar = top + height

Senin solid değerlerin:

left   = -8
top    = -40
width  = 16
height = 16

X aralığı:

Sol = -8
Sağ = -8 + 16 = 8

Y aralığı:

Üst = -40
Alt = -40 + 16 = -24

Bu yüzden:

X = -8 ile 8
Y = -40 ile -24

Hero box:
left: -14.86
top: -23.32
width: 14
height: 20

Hero box:
X = -14.86 ile -0.86
Y = -23.32 ile -3.32

___

X eksenini sayı doğrusu gibi düşün:

Hero:  -14.86 ---------------- -0.86
Solid:         -8 ---------------------- 8
|<-- ortak alan -->|

Hero ve solid’ın ortak X alanı var:

-8 ile -0.86

Bu nedenle X ekseninde kesişiyorlar.

Boşluğun hesabı:

HeroTop - SolidBottom
= -23.32 - (-24)
= -23.32 + 24
= 0.68

Yani solid -24 konumunda bitiyor, Hero ise -23.32 konumunda başlıyor. Aralarında 0.68 birim boşluk var.
